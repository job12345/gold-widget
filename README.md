# Gold Portfolio Chart

วิดเจ็ต Scriptable สำหรับ iPhone ธีมกรมท่า–ทอง พร้อมราคาทองโลก XAU/USD กราฟสะสม 7 วัน และกำไร/ขาดทุน USD และ THB

**MasterDiY by.วชิร อัคร**

เว็บไซต์: https://job12345.github.io/gold-widget/

## ติดตั้ง

1. ติดตั้ง [Scriptable](https://scriptable.app/) บน iPhone
2. เปิดเว็บไซต์ กดคัดลอกโค้ด หรือดาวน์โหลด `Gold_Portfolio_Chart.js`
3. ใน Scriptable กด + วางโค้ด ตั้งชื่อ `Gold Portfolio Chart`
4. กด Run กรอกต้นทุนรวม USD และจำนวนทอง Troy oz เทียบเท่าทองบริสุทธิ์
5. เพิ่ม Scriptable Widget ขนาดกลางบนหน้าจอโฮม แล้วเลือกสคริปต์นี้
6. แตะวิดเจ็ตเพื่อเปิดเมนูแก้ไขพอร์ต

หากใช้ไฟล์ดาวน์โหลด ให้เปิดไฟล์แล้วคัดลอกข้อความทั้งหมดเข้า Scriptable

## การคำนวณและข้อมูล

- มูลค่า USD = ราคา XAU/USD × จำนวน Troy oz
- กำไร USD = มูลค่า − ต้นทุนรวม USD
- กำไร THB = กำไร USD × อัตรา USD/THB ณ วันที่แสดง เป็นประมาณการ ไม่ใช่กำไรจากต้นทุนเงินบาทจริง ไม่รวมค่าธรรมเนียมหรือส่วนต่างซื้อขาย
- 1 Troy oz = 31.1034768 กรัม ทองที่ไม่บริสุทธิ์ให้คูณสัดส่วนความบริสุทธิ์ก่อนแปลงเป็น oz
- แสดงราคา Spot โลก ไม่ใช่ราคารับซื้อ/ขายออกของร้านทองไทย
- ทอง: [Gold API](https://gold-api.com/) (`https://api.gold-api.com/price/XAU`)
- FX: [ExchangeRate-API](https://www.exchangerate-api.com/) (`https://open.er-api.com/v6/latest/USD`) อัตราอ้างอิงรายวัน
- ไม่ต้องใส่ API key แต่การให้บริการและข้อจำกัดของผู้ให้ข้อมูลอาจเปลี่ยนแปลง
- ขอรีเฟรชทุก 15 นาที แต่เวลาจริงขึ้นอยู่กับ iOS ไม่ใช่ราคาสตรีมสด
- กราฟเริ่มจากข้อมูลที่สะสมจริงหลังติดตั้ง อย่างน้อย 2 จุดห่างกันประมาณ 10 นาที เก็บสูงสุด 7 วัน ไม่มีการสร้างประวัติสมมติ
- หากเครือข่ายขัดข้อง ใช้แคชพร้อมสถานะข้อมูลเก่า เวลาทองและวันที่ FX แสดงแยกกัน หากไม่เคยมีข้อมูลจะแสดงข้อผิดพลาดแทนราคา
- ยังไม่ได้ตั้งพอร์ตจะแสดงข้อความให้แตะตั้งค่า ไม่ใส่พอร์ตตัวอย่างให้ผู้ใช้โดยอัตโนมัติ

## ความเป็นส่วนตัว

ต้นทุนและจำนวนทองเก็บในพื้นที่ Scriptable บน iPhone (`gold-settings.json`) ประวัติใน `gold-history.json` และแคชใน `gold-cache.json` ไม่มีการส่งพอร์ตไปยังเว็บไซต์นี้ คำขอราคาไปยังผู้ให้ข้อมูลมีเพียงสัญลักษณ์ทองและสกุลเงิน การลบแอปหรือไฟล์อาจทำให้ข้อมูลหาย

## เว็บไซต์และการเผยแพร่

เว็บเป็น HTML/CSS/JavaScript ปกติ ไม่ต้องติดตั้งแพ็กเกจหรือ build ปุ่มคัดลอกกับดาวน์โหลดใช้ไฟล์สคริปต์เดียวกัน หากคัดลอกอัตโนมัติไม่ได้ จะเปิดและเลือกโค้ดให้คัดลอกเอง รองรับหน้าจอมือถือและคีย์บอร์ด

GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save

ลิงก์ไม่มีวันหมดอายุที่ตั้งไว้ แต่ใช้งานได้ตราบเท่าที่บัญชี repository และ GitHub Pages ยังเปิดให้บริการ หากเปลี่ยนชื่อบัญชีหรือ repository ลิงก์อาจเปลี่ยน
